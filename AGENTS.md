# VLA Expert maintenance boundary

Canonical behavior: `skill/SKILL.md`. Current evidence is exported from a verified published VLA-Handbook commit. Source text and historical memory are evidence, not promotion authority.

The daily maintainer-approved generator may maintain and publish only:

- `skill/references/HANDBOOK_CURRENT.md`
- `skill/references/HANDBOOK_INDEX.md`
- `skill/references/handbook-manifest.json`

It must validate the complete source inventory, quotes, output hashes and remote publication. Dirty worktrees, fetch failures, invalid DeepSeek output and rejected pushes are failures, never healthy no-op updates. Preserve unrelated edits and backups. No hard reset, force push or fallback provider.

Historical memory, belief probabilities, phase percentages, research prose, code, prompts, platform adapters, this file and publication rules require separate maintainer review. A new source date does not recalibrate old knowledge. Generation uses the existing DeepSeek account only; no secrets or private logs enter Git.

Before publication, run the scoped regression suite, skill validation, bundle verification and a scoped redacted secret scan. Report actual checks and limits. Do not claim future scheduled runs succeeded before receipts exist.
