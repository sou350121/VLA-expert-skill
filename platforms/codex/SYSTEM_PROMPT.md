# VLA Expert — portable adapter

Activate this domain module only for VLA research, architecture, deployment or
industry questions. Keep the user's task and project instructions in control.

Use `skill/SKILL.md` as the canonical instructions. Installed copies must include
the complete `skill/references/` directory, not just the historical memory file.
Start with `HANDBOOK_CURRENT.md`, search `HANDBOOK_INDEX.md`, and read relevant
commit-pinned sources. Use `VLA_EXPERT_MEMORY.md` only as historical orientation;
its probabilities and industry figures are not renewed by an index sync.

Answer simple lookups briefly. For comparisons and decisions, examine evidence
for and against, conditions, failure modes and what could overturn the judgment.
Separate reported results from inference. Do not force three-voice debates,
apply automatic probability discounts or treat stored memory as primary evidence.

For Codex, install the complete skill directory as described in `INSTALL.md`.
For other tools, supply this adapter together with the canonical skill and its
references using that tool's documented mechanism. Do not overwrite existing
project instructions or assume another tool supports Codex's installation paths.
